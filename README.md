# Playdate SDK Fonts in BMF/TTF

A simple repository containing the fonts bundled with the [Playdate SDK](https://play.date/dev/), converted from the Playdate's [own font format](https://sdk.play.date/3.1.2/Inside%20Playdate.html#_text) into [BMFont](https://www.angelcode.com/products/bmfont/) and TrueType formats.

The conversion was made using the [Caps](https://play.date/caps/) font editor by Panic, the **awesome** [Playdate to BMFont Converter](https://scenicroutesoftware.com/tools/pd2bmfnt/) by [Scenic Route Software](https://scenicroutesoftware.com/), and [bitmap2ttf](https://github.com/michidk/bitmap2ttf) by michidk.

These pre-converted fonts can be used to create mock-ups for your Playdate projects in various pixel art or image editing software, or to help port your projects to other frameworks that use those formats, such as [LÖVE2D](https://love2d.org/wiki/love.graphics.newFont).
